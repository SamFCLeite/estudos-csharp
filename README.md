# Estudos de C#

Repositório criado para registrar minha jornada de aprendizado em **C#, .NET e Programação Orientada a Objetos**.

Aqui estão exercícios e pequenos projetos desenvolvidos durante meus estudos, principalmente com base no curso **C# COMPLETO Programação Orientada a Objetos + Projetos**, do professor Nélio Alves.

O objetivo do repositório é registrar, de forma prática, os conceitos que estou aprendendo e como eles são aplicados em código.

---

## 📁 CadastroBanco

### Objetivo

Projeto desenvolvido para praticar conceitos básicos de **Programação Orientada a Objetos em C#**, utilizando como exemplo um sistema de cadastro relacionado a contas bancárias.

### O que foi usado

* **Classes e objetos:** criação das estruturas que representam os elementos do sistema.
* **Encapsulamento:** controle do acesso aos dados das classes.
* **Construtores:** inicialização dos objetos no momento de sua criação.
* **Propriedades:** acesso e manipulação dos dados dos objetos.
* **Métodos:** definição dos comportamentos das classes.
* **Sobrecarga:** criação de diferentes versões de métodos/construtores.
* **Composição:** utilização de objetos dentro de outros objetos.
* **Listas:** armazenamento e manipulação de vários objetos.
* **Organização de responsabilidades:** divisão das funcionalidades entre diferentes classes.

## 📁 OderSummary

### Objetivo

Projeto desenvolvido para praticar **composição de objetos e relacionamento entre classes**, utilizando um sistema de pedidos como exemplo.

O projeto representa um pedido contendo diferentes informações, como cliente, produtos e seus respectivos dados, permitindo praticar como diferentes objetos podem trabalhar juntos.

### O que foi usado

* **Classes e objetos:** representação dos elementos do sistema.
* **Encapsulamento:** proteção e organização dos dados.
* **Construtores:** criação e inicialização dos objetos.
* **Composição:** objetos formados por outros objetos.
* **Associação entre classes:** relacionamento entre diferentes entidades.
* **Listas:** armazenamento de vários itens dentro de um pedido.
* **Enumerações (`enum`):** representação de estados ou categorias.
* **Propriedades:** acesso aos dados das entidades.
* **Métodos:** implementação dos comportamentos necessários.
* **Organização de entidades:** separação das diferentes responsabilidades do sistema.
